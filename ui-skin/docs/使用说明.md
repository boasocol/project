# UI 换肤交付包

交付包包含打包器、字体、样例素材和两份三屏布局模板。新皮肤的素材与布局放在同一个目录，程序和美术使用同一份清单。

## 开始打包

1. 按《交付规范》准备主界面、倒计时和闹钟的干净背景、全显稿、精灵和动画。
2. 从包内 `ui_layout.guofeng.json` 或 `ui_layout.circus.json` 复制一份到素材目录，改名为 `ui_layout.json`。调整坐标、字号、控件是否显示和精灵组。倒计时三个按钮沿用开始/暂停、重置、退出。
3. 把素材目录拖到 `一键打包.bat`，或执行 `python scripts/pack_style.py <素材目录> <产物根目录>`。运行环境需要 Pillow 和 NumPy。采用定制数字或精灵构建器的样式使用随附入口，马戏团使用其 `scripts/pack_circus.py`。
4. 检查产物里有 **2,097,152 B** 镜像，且 `build_info.txt` 显示 `SKIN v1 (3 screens)`。将整个产物包按《回传清单》交回。

产物目录包含镜像、字库和精灵中间文件、素材快照以及 SHA-256。使用交付包自带的旧 08 号素材时，仍可生成旧版兼容镜像。

## 烧录

首次使用三屏布局需要更新 MCU 固件。之后换肤在外置 SPI Flash 的 `0x000000` 写入对应的完整镜像。开机串口 `[UI] SKIN flash (3 pages)` 表示三屏表已校验并生效。

**在板烧录存储 IC 时先按住 左键 + 右键再上电**：烧录器给 Flash 供电会反灌到板子、把主控"半上电"启动，主控一旦初始化 SPI1 就会和烧录器抢总线，表现为烧录失败或校验错。固件对此做了保护——上电瞬间检测到左右键同时按住，就**不初始化 Flash SPI、不点屏、不打印**，停在原地等断电（此后松开按键也不会启动，必须断电重上电）。松开按键、重新上电即恢复正常。

## 排查

- 打包提示缺字或布局越界时，按报错调整对应的文字框、字号档位、精灵编号或素材尺寸。
- 主屏、倒计时或闹钟的动态元素与底图重影时，检查使用的是否是同版干净背景，并核对坐标是否取左上原点。
- 旧包只含倒计时块时，串口会显示 `[UI] CNTL flash`。完整三屏包应另外显示 `[UI] SKIN flash (3 pages)`。
