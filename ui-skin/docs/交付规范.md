# 三屏 UI 换肤交付规范

这份规范用于支持 SKIN v1 的 320×240 语音时钟。首次升级 MCU 后，切换符合本规范的皮肤只需要烧录对应的外置 Flash 镜像。

## 素材和布局

- 三张干净背景 PNG 和三张同底图的全显稿，分别对应主界面、倒计时、闹钟。数字、会变化的文字和图标应从干净背景去除，静态装饰可以保留。
- 动态精灵用透明素材。开关和星期状态要给开、关两态，也可用底图作为关态。机器人按 125 ms/帧提供，每个状态 1–16 帧。动画的落点由精灵索引中的坐标决定。
- 在素材目录放置 `ui_layout.json` 和 `_清单.txt`。`ui_layout.json` 声明三屏的布局与精灵语义映射，`_清单.txt` 声明打包用到的素材文件名、字体和字号档位。以 `ui_layout.guofeng.json` 或 `ui_layout.circus.json` 为模板。
- 交付实际用到的素材、清单、打包产物和预览。使用自定义精灵或字库构建器时把脚本一并交回，确保可以从素材复打。

## 布局清单字段

坐标以左上角为原点，X 向右、Y 向下。矩形用 `[x, y, 宽, 高]`，单位都是像素。颜色用 `#RRGGBB`。字号档位从 0 起，对应 `_清单.txt` 的 `font_sizes`。位图字库支持 1bpp 和 4bpp。

| 位置 | 字段和用途 |
|---|---|
| `main` | `numbers` 定义时分数码。可选 `seconds` 可以填 `null`。日期分隔符支持点、横线和斜线。日期、星期、农历、温湿度、标题各有独立文字框和字号。可选整点报时开关引用自己的两态精灵。 |
| `countdown` | 分别提供两位、三位分钟的数码位置和共用擦除区。标题可配两条装饰线，用 `null` 省略。进度支持连续竖条、1–8 个矩形或椭圆分段，以及隐藏。分段按从先消失到最后消失的顺序排列。 |
| `countdown.buttons` | 三个槽位按顺序为开始/暂停、重置、退出。`actions` 可省略，填写时固定为 `["toggle", "reset", "exit"]`。皮肤可以调整三个槽位的位置、字号和颜色。第一个按钮随计时状态显示「开始」或「暂停」；「退出」回主屏，正在运行的计时留在后台。 |
| `alarm` | 槽号可用文字或连续三张数字图。开关声明独立的开关两态。星期按周一至周日提供七项，每项可用不同精灵或填 `null`。可选 `switch_blink_cover` 给烘焙在背景上的开关文字准备闪灭贴片。 |
| 每页 `bubble` | 定义文字区域、行高、行数、主/备用字号、颜色、对齐和默认文案。填 `null` 隐藏整页气泡。默认文案最多 63 个 UTF-8 字节，可用 `\n` 指定换行。布局内新增文案由交付包字库工具自动收录。 |
| 每页 `robot` | 按 `idle`、`wake`、`ring`、`ack` 指定首个精灵 ID 和帧数。省略状态时回退到 `idle`，省略整组即隐藏。 |
| `overlays` | 可从素材目录内的 PNG 追加具名精灵，可选裁切矩形。例如马戏团从全显稿截取整点报时打开态，并用名称引用。 |

数码组仍需要连续十个精灵，冒号可独立编号。开关、星期钮和槽号等语义由布局清单映射，不同皮肤可以有不同的精灵编号和总数。控件框、闪灭擦除区和动画区域须给彼此留出空间。文字 Y 坐标是字形单元格顶部，需要根据字体墨迹与基线留量。

## 打包和验收

1. 新皮肤从样例复制出 `ui_layout.json`，放到素材目录。使用交付包打包入口，或采用随风格提供的定制构建入口。
2. 打包器校验布局边界、字体、编号与容量，生成 **2,097,152 B** 的 `flash_image_px.bin` 和 `build_info.txt`。三屏包的构建记录显示 `SKIN v1 (3 screens)`，素材快照同时保留布局清单。
3. 固件开机串口出现 `[UI] SKIN flash (3 pages)` 后，依次验收三屏。至少检查时间、日期和温湿度，计时两种位数、开始暂停及返回，闹钟三槽、开关、星期和设置闪灭。
4. 固件区首次更新一次。后续换肤把镜像从外置 SPI Flash 地址 `0x000000` 完整写入即可。新镜像也要符合本规范。

三屏包在 `0x100` 写入倒计时几何块 CNTL，在 `0x200` 写入三屏块 SKIN。固件校验两个块的版本、长度和 CRC 后一起启用。单独的 `countdown_layout.json` 属于上一版倒计时兼容入口。两种清单各自对应单独的交付路径。
