# 三屏 UI 回传清单

- 素材目录内提供三张 320×240 干净背景、三张同版全显稿、机器人动画和各控件的精灵。缺省状态写在布局清单里。
- 随素材提供 `ui_layout.json` 和 `_清单.txt`。三屏的道具位置、可见性、字号、颜色、动画组和精灵语义均使用布局清单。全显稿保留作视觉对照。
- 一起回传整个打包产物，包含 `flash_image_px.bin`、`build_info.txt`、布局与素材快照。若有定制构建脚本，一并回传与本镜像匹配的版本。

## 出包前自检

1. 镜像大小为 **2,097,152 B**，`build_info.txt` 显示 `SKIN v1 (3 screens)`。
2. 检查字库预览、数码、开关两态、星期按钮和各状态动画。精灵数量以本风格实际配置为准。
3. 三张干净背景与三张全显稿一一对应。动态区域留空，闪灭时能恢复同一块背景。
4. 检查各页的默认和临时气泡文字是否能折行。测试两位/三位分钟、同一按钮启动和暂停、重置及退出，以及闹钟槽号、星期和开关。
